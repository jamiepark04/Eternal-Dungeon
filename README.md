# Eternal-Dungeon

# Features
- Maze generation utilizing the binary space partition algorithm
- Physics based movement using the Unity physics engine
- Mutliple hitscan weapons with ammo and powerups
- Multi-state enemy AI configuring enemy behavior
- Post game scoreboard

# How to Play
  1. Download Build & Open
  2. Open Eternal_Dungeon.exe
  3. Click Play & Read Controls
